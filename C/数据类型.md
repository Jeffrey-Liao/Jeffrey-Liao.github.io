# 数值类
## int/short/long/long long
## short
- 大小：2个字节（16位）
- 取值范围：$0\to\pm2^{16-1}$（一共16位，去掉符号位）
- 存储整数
- 有的时候存储一些比较小的数字的时候使用更大的空间比较浪费。

### int
- 大小：4个字节（32位）
- 取值范围：$0\to\pm2^{32-1}$（一共32位，去掉符号位）
- 存储整数

### long
- 大小：4个字节（32位）
- 存储整数
- 取值范围：$0\to\pm2^{32-1}$（一共32位，去掉符号位）
- 这个玩意可以看成int，只是在有些老的设备上int是2个字节，所以long用来表示4字节

### long long
- 大小：8个字节（64位）
- 取值范围：$0\to\pm2^{64-1}$（一共64位，去掉符号位）
- 存储整数
