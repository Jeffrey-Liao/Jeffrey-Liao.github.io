# 字面量和变量
## 字面量
>字面量是指，可以被**人直接看见的数值、字符串等**
```c
int n = 3;//3就是数值字面量
const char* str = "我爱毕小宇";//...就是字符字面量
```

字面量大致可以分为两类
- 字符
	- 字符`'c'`
	- 字符串`"char"`
- 数值
	- 整数
		- int`123`
		- long long`123l`//最后这个是L(小写)
	- 浮点数
		- 单精度（float）`1.2f`
		- 双精度（double）`1.2`

字面量对于计算机来说没意义，在**编译过程**中会被直接**写入变量**

## 变量
>变量是指计算机内存中的值，是可以被一些操作改写的。

变量值的来源有两种
- **其他计算机内存位置里的值**
- **编译时编译器写入的字面量**
# 数值类
## int/short/long/long long
### short
- 大小：2个字节（16位）
- 取值范围：$\pm2^{16}-1$（一共16位，去掉符号位）
- `0(符号位) 000 0000 0000 0000(数值位)`
- 存储整数
- 有的时候存储一些比较小的数字的时候使用更大的空间比较浪费。

### int（最常用的）
- 大小：4个字节（32位）
- 取值范围：$\pm2^{32}-1$（一共32位，去掉符号位）
- 存储整数

### long
- 大小：4个字节（32位）
- 存储整数
- 取值范围：$\pm 2^{32}-1$（一共32位，去掉符号位）
- 这个玩意可以看成int，只是在有些老的设备上int是2个字节，所以long用来表示4字节

### long long
- 大小：8个字节（64位）
- 取值范围：$\pm2^{64}-1$（一共64位，去掉符号位）
- 存储整数

### 存储方式
#### 二进制表示
- `0000 0000`，表示一个字节（中间使用空格分开让人好读一些，不然我写个10110001111101你看的绝对头大）
- 所以如果使用`int`，在计算机里，就是表示为`0000 0000 0000 0000 0000 0000 0000 0000`

![](pic/Pasted%20image%2020260113205302.png)
- 在`int`中，第一位是符号位，当第一位**为1**时，则表示数据为**负数**，如果**为0**时表示数据为**正数**。
- 这也是为什么取值范围$-1$的原因，因为**第一位不参与表示数据**

#### 二进制运算基础
- 在C和其他的编程语言中，大多都使用**IEEE 754**标准。即对需要求负数的数进行**取反再求补操作**。

##### 取反
- 将当前所有的二进制位翻转：`0010`->`1101`
- 原来是`1`的变成`0`，原来是`0`的变成`1`（挖藕，还有攻受转换）

| 原先数值 | 转换后的数值 |
| ---- | ------ |
| 0    | 1      |
| 1    | 0      |
| 1    | 0      |
| 0    | 1      |


##### 二进制运算和截断
- 加法
	- $1001+0001 = 1010$：将相同位置的`1`相加后进位，如果是`1,0`相加就不变
- 或
	- $1001 \lor 1010= 1011$（$\lor$表示或，在C中写做`||`(这个键在你回车键的上面，按住shift)）：只要两者其一是`1`那这个位置就变成`1`

| 原先数值1 | 原先数值2 | 转换后的数值                |
| ----- | ----- | --------------------- |
| 0     | 1     | 1(`0 or 1`因为有一个1所以是1) |
| 1     | 0     | 1                     |
| 1     | 0     | 1                     |
| 0     | 1     | 1                     |

- 与
	- $1001 \land 1010=1000$（$\land$表示与，在C中写做`&&`）：必须两个位置都是`1`才是`1`

| 原先数值1 | 原先数值2 | 转换后的数值                   |
| ----- | ----- | ------------------------ |
| 0     | 1     | 0(`0 and 1`因为有一个**不是1**) |
| 1     | 0     | 0                        |
| 1     | 0     | 0                        |
| 0     | 1     | 0                        |

- 非
	- $\lnot0110=1001$（$\lnot$表示非，在C中写做`!`）：这个是把之前的0变成1，1变成0（看刚刚的取反）
##### 求补
- 在二进制数据的末尾+1：`0101`->`0110`

##### 截断
>如果我们限定当前运算的位数之后，**超出约定位数的数值会被截断**。
- 假设我们约定**约定位数是4**：$1111+0001=1\:0000$，此时1已经超出我们约定的四位范围，所以我们将1截断，所以这个运算的结果是`0000`

### 定义和声明整数类型变量
```c
int intVar;
//声明时，将变量名称尽可能命名成变量的用途
//比方说这个变量你看名字就知道是一个int Variable
//将开头字母小写后面接续的单词首字母大写的命名方式叫做驼峰命名法，这个你以后会学到，现在就先这样用。
short shortVar;
long longVar;
long long longLongVar;
```
上面的都是声明，只是告诉编译器有这个变量且为其分配内存。**但是**，在这些**变量中的值**都是**不！确！定！** 的。

思考下面的代码会输出什么
```c
int main()
{
	int a;
	printf("a的值是：%d",a);
}
```
你猜出来是什么了嘛？

错啦！

你要问为什么我知道你错了，因为这个`a`的值压根就是**随机的**！谁都不知道是多少，可能是`5201314`，`114514`这些，**没有人确定！！！！！**

#### 定义和声明的区别
前面说了，声明的意义是：
>告诉编译器有这个变量且为其分配内存。但是**内存中的值不确定**。

而**定义**的重要性就是把主动权抓在我们手上，**让它的值确定**。

```c
int intVar = 0;
short shortVar = 0;
long longVar = 0;
long long longLongVar = 0;
//从这里开始，上面的所有变量我们都可以保证，里面的值为0
```

总结来说：
>定义是让计算机资源变得可控的一个步骤，任何的变量都**应当先定义（初始化）后再使用**！

#### 此外
其他语言像java和C#这些类C语言（即使用和C很相似的语法）提供了默认的初始化操作，即:
```java
int a;
//等价于
int a = 0
```

但是我们还是最好养成初始化的好习惯，**在使用所有变量前，都设置它们的初始值**。

### 浮点数的二进制表示
#### 从十进制到二进制（现实中一般不考你这么变态的问题，基本上也不会用到，你看看就行）
1. 将十进制小数 **乘以 2**。
2. 记录结果的**整数部分**（只能是 0 或 1），作为二进制小数的一位。
3. 取结果的**小数部分**，重复第 1 步。
4. 重复直到小数部分变为 0（有限二进制）或达到所需精度（无限循环时截断/舍入）。

转换0.1

|步骤|小数 × 2|整数部分|小数部分|
|---|---|---|---|
|1|0.1 × 2 = 0.2|0|0.2|
|2|0.2 × 2 = 0.4|0|0.4|
|3|0.4 × 2 = 0.8|0|0.8|
|4|0.8 × 2 = 1.6|1|0.6|
|5|0.6 × 2 = 1.2|1|0.2 ← 重复了！|
|6|0.2 × 2 = 0.4|0|0.4|
|...|...|...|...|

这个例子展示了，计算机存储某些小数时使用的是近似存储，所以会**存在精度丢失**的问题。比方说刚刚的0.1就无法被计算机完美表示。

### ASCII的作用
>之前说过，计算机中的所有的东西其实都是数字。为了**表示字符**，所以就人为地**建立**了这样一个**关系**，使得部分**二进制数可以在需要的时候被转为字符**。

### 字符编码规则
>字符编码就是将二进制数转换为字符的规则

现在常用的字符编码有：
- UTF-8
- UTF-16
- GBK（中文）

### UTF(Unicode Transformation Format)
用一至四个字节对Unicode字符集进行编码，即一个字符被表示为一个字节或者四个字节（根据语言需求。
- 比方说中文就被编码为两个字节，生僻字被编码为三个或者四个字节。

#### 字符集冲突
有的时候你会在网上看到一些段子，比方说一些中文被表示成了乱码，一些英文被表达成了一些奇怪的中文比方说：
- 锟斤拷锟斤拷锟斤拷
- 烫烫烫烫烫烫烫

这些就是字符集发生了冲突，因为**不同字符集使用的规则不同**，所以**同样的编码** *在不同的字符集里可能是完全不一样的东西*。

比方说shabi在中文里是傻逼但是在英文里就是破旧的（shabby）

但是有一类编码是永远不会错误的，就是ASCII编码，因为**所有的编码规则都把最前面的127个位置留给了127个ASCII编码**。

**所以也是为什么永远不要给你的文件夹命名为中文！！！！！！！！！**，因为读取文件路径的软件不一定支持中文字符集。

#### 中文的表示方法
计算机无法理解中文，26个英文字母大不了全都存一遍，反正也不会浪费多少时间。但是中文光常用字就已经超过3000个了，全部存下来有点太抽象了。而且计算机也没法知道怎么去显示中文。

所以中文使用的是矩阵坐标法表示中文。以下表格只是作为教学示范，不代表实际编码。

| 坐标  | 00  | 01  | 10  |
| --- | --- | --- | --- |
| 00  | 我   | 爱   | 毕   |
| 01  | 小   | 宇   | 捏   |

(00,00),(00,01),(00,10),(01,00),(01,01),(01,10)（嘻嘻）
(00,10),(01,00),(01,01),(00,01),(00,00),(01,10)（是吧？嘿嘿嘿）

所以这就是为什么**中文字符占两个字节**（char只占一个字节，所以不能用char存储单个中文字，会出错）。因为中文字符需要一个字节给x坐标，一个字节给y坐标。

## 前缀类型
>前缀类型是一类给刚刚上面列出的类型实现附加功能的类型，一般写在**变量类型的前面**。不过有特例，会在指针部分介绍。

### const
>`const`是constant的简写，表达**不可变的**，**不可修改的**，所以被const修饰的变量都不能被修改
```c
const int constVar = 0;
constVar = 10;//非法！编译器会给出错误信息，因为constVar不可修改！
```

### unsigned
>unsigned用于**将变量转为非负数**。但是只能用于整数类型和char，不能用于浮点数类型！！

```c
unsigned int u_intVar = 0;
unsigned u_intVar2 = 0;//等价于unsigned int
unsigned long u_longVar = 0;
unsigned long long u_longLongVar = 0;
```

诶， 那你可能会好奇，如果我给-1赋值给一个`unsigned`变量它就会变成一呢？

答案是$4294967295=2^{32}$。

为什么？？？？？？？

![](pic/Pasted%20image%2020260113225405.png)
因为我们的无符号整数把第一个位置变为了正常的数据位，所以`-1,1111 1111`（使用反码求补方法存储的，我希望你还记得）就被解释为了一个`1111 1111`的数据，也就是当前位数的最大值$2^n$

那么由于`unsigned=unsigned int`是四个字节，所以就是32位，所以$-1$在`unsigned`就被解释成了$n=32$时的最大值，即$4294967295=2^{32}$

### static
>表明当前**资源**只会被**分配一次**（注意，不是变量）

这是一个比较复杂概念，我们看一个例子
```c
void func()
{
	int var = 0;
}
```

如果我们使用`func()`，每次都会创建一个新的`var`，虽然他们名称相同，但是指向的实际资源实际上不一样。（就像世界上可能还有一个人叫毕小宇，但是ta肯定没有你这么迷人，美丽）

`static`就很好地解决了这个问题，在后面每次调用`func`时，这个var表示的资源都是一样的。
```c
void func()
{
	static int var = 0;
}
```

#### 更复杂的例子
```c
int func()
{
	int var = 0;
	var +=1;
	printf("var:%d\n",var);
}
int main()
{
	func();
	func();
	func();
	func();
}
```
在上面的例子中，屏幕上会一直出现`var:1`，因为每个`func`中的`var`都只是同名同姓而已。
![](pic/Pasted%20image%2020260113230809.png)

```c
int func()
{
	static int var = 0;
	var +=1;
	printf("var:%d\n",var);
}
int main()
{
	func();
	func();
	func();
	func();
}
```
这个例子里，输出就是`var:1,var:2,var:3,var:4`，因为每个`func`中的`var`实际上都是一个`var`

## 数组
>代表了**有限个**共用**同一个名称**的**不同变量**

### 声明
```c
int arr[5]={0};//{0,0,0,0,0}
arr[0] = 10;
*arr
//创建了一个叫做arr的int数组，一共有5个元素
```
![](pic/Pasted%20image%2020260113231403.png)
`arr`的`[]`中一定要给一个初始值，因为看上面定义，数值代表了**有限个**元素。所以如果不限制大小，C语言编译器将会视作**语法错误**。

`arr`就像班级，这个0-4的叫做**下标**，就是班级同学的名称，只是他们变成数字了，类似于同学0号，同学2号，同学3号这样。

### 定义
```c
int arr[5] = {0};
//等价于
arr[0] = 0;
arr[1] = 0;
arr[2] = 0;
arr[3] = 0;
arr[4] = 0;
```
所以这也是为什么我提到了，数组其实就是**一组使用同一个名称的不同变量**。因为他们都叫`arr`，但是`arr[0]`和`arr[1]`的数据互相独立，就像两个变量一样，也**就是两个变量**。

很多书上没有讲清楚这个概念，所以导致有些人对于数组的概念很晕。

注意，如果没有`={0}`，数组里面的所有变量的**初始值**也**不确定**！！！！

#### 另一种方法
```c
int arr[] = {1,2,3,4}
```
这个时候`[]`中就不用写明大小了，因为后面的列表（初始化列表）已经写明了这个数组有四个元素，分别是`1,2,3,4`。

```c
int arr[5] = {1,2,3,4}
```
当然这样也是可以的，不过下标4的元素中的值不确定，因为只初始化了0,1,2,3。

这个**列表**可以短于前面数组的长度，但是**不能长于前面数组的长度**！
### 操作
- 取下标操作`arr[0]`，表示使用数组中第0个元素（变量）进行操作（赋值，计算等）
- 数组**没有**赋值操作，**没有**拼接操作，没有比较操作，若`arr1[3]={1,2,3}, arr2[2]={4,5}`**不存在**：
	- `arr1=arr2 -> arr1中为{4,5,3}`**（该操作不存在！！！）**
	- `arr1==arr2 -> 比较结果为false`**（该操作不存在！！！）**
	- `arr1 = arr1+arr2 -> arr1中为{1,2,3,4,5}`**（该操作不存在！！！）**
	- `arr1.size()-> 返回长度3`**（该操作不存在！！！）**
 - 如果要进行比较或者赋值，需要使用以下方法

 ```c
 int size = sizeof(arr1)/sizeof(int);

 ```

## 结构体
>结构体是一个**自建类型**，用来将多个不同类型的变量组合到一起，以用来描述某些现实世界的复杂事物。在没有使用这个类型创建对象（变量）时，这个类型包含的内容不存在。

```c
struct MyStruct
{
}

typedef struct MyStruct MyStruct
//使用这个方法可以将struct MyStruct缩短为MyStruct
```
这就是一个最简单的`struct`。具体里面有什么由你这个设计者决定。

### 一个栗子
#### 结构体的建立
```c
struct Student
{
	char[20] name;
	int age;
	char[20] school;
	int GPA;
	int year;
}
struct Struct variable;
variable.age  = 10;
variable.school = "hello";
int main()
{
}
```
这里我创建了一个叫做学生的**模板**，使用以上的信息去描述一个学生。注意，如果我在main函数中想要**调用**`name,age`这些变量是**不行的**。因为它现在**只是一个模板**，没有分配任何的资源，**没有占用任何的内存**。

这些`name`什么的叫做**成员变量**或者**属性**（attributes）。这些变量就像Student的一个成员一样，他们**不能脱离模板存在**，也**不会**在模板没有被应用时**被创建**，

---
#### 结构体成员的访问
```c
//我就不重新写一遍struct了
int main()
{
	struct Student liaoRunkang = {"廖润康",22,"ELTE",1,3};
	
	struct Student biXiaoYu;
	biXiaoYu.name = "毕小宇";
	biXiaoYu.age = 18;
	biXiaoYu.school = "ELTE";
	biXiaoYu.GPA = 0;
	biXiaoYu.year = 1;
}
```
在上面这个时候，才基于结构体的结构，创建了两个实体，这个时候**上面的那些成员变量才实际占用内存**。这就像你抖音里的视频模板，在你没有用的时候，它们只是摆在那，只有你创建了一个新的视频之后他们才会变成实际的视频。

初始化成员有两种方法，它们是等价的。

下面这种方法还可以用于**访问成员变量**用于**修改成员变量的值**。

```c
int main()
{
	liaoRunkang.age = 23;//到2026年的3月13号就可以修改了
	biXiaoYu.age = 19;//到2026年的10月18号就可以修改了
	//刚刚其他的不变
}
```

#### 核心思路
结构体的语法非常简单，难难在如何去设计一个结构体，其传达的思想非常复杂，很多人讲了很多，花了很多章节很多页也没讲清楚。

其实就一句话
>使用计算机，用尽可能**简单和贴切的方式去描述现实世界的事物**

如何创建，修改结构体在语法上都不难，难就难在如何去创建一个结构体使他可以很好地描述一个现实世界的事物。这个问题没有标准答案，也可能会随着代码的增长发生变化。

但是核心就是，对于一个现实的事物，你如何去描述他，而你又要忽略掉哪些没有必要的东西。

比方说，我们现在要去写一个学校的学生管理系统。那我们就要去思考，我**如何去描述学生**，学生身上有哪些这个系统必须需要的共性。那我们把这些共性收集起来，**按照这些共性去创造一个结构体**，或许就能用计算机描述学生，这样一个现实世界存在的抽象事物。

这个就是**面向对象设计**(Object Oriented Programming)的基础。而OOP是现代代码开发**最基础的部分**。

```c
struct Student
{
	char[20] name;
	int age;
	char[20] school;
	int GPA;
	int year;
	char[20] department;
	char[20] nationality;
	...
}

```

所以，如果想要写好代码，不仅仅是要学习技术和知识。**还要去学会如何描述这个世界，如何认识这个世界**，如何在很多繁杂的信息中提炼出最有用的部分。保持对一切的好奇和探索欲，思考那些没什么人想过的事情，就是我这一路走来，最大的感悟 o(\*￣︶￣\*)o。

所以，如果有些不切实际的想法，就一直想下去，**解决看似不可能解决的问题就是计算机科学的魅力**。
