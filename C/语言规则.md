# C 语言规则

# 声明和定义
## 声明
>计算机通过声明**得知一个程序元素的存在**（变量，函数的名称，类型（返回值类型），大小）。并为其执行某些操作，如预留内存空间。

## 定义
>计算机不仅知道上述声明的所有信息，同时知道程序元素具体的信息如**变量中的值**和函数的函数体。

## 举例
```c
int n; //声明
int n = 0;//定义

void function();//声明
void function()
{
	printf("love you");
}
```
在这里，`n`在声明时被计算机分配了`sizeof(int)`大小（4字节）的内存


# 语言成分
## 关键字(Keyword)
>关键字是所有C语言保留的，**具有特殊含义的词的合集**
>包括以下这些：
- 类型关键字：用于标识变量、函数返回值类型。或是某些具有特殊含义的**前缀**
	- int/long/long long/short
	- unsigned/const/static/volatile
	- double/float
	- char
	- void
	- union
	- struct
	- sizeof
	- enum
	- typedef	
- 控制结构关键词：用于定义控制结构
	- if/else/else if
	- switch/case/default
	- while/for/do/break/continue
	- return

共计34个，这里只列出常见且会被用到的关键字。

正因为此，C语言也被称为"最简单"的语言，因为只有34个关键字，是所有常用语言中最少的。

当然，这是一个入门简单，但精通极其困难的语言。就连我在我自己的网站上也只写了，`熟悉C/C++`。
## 标识符(Identifier)
>标识符是一切程序员自己定义的变量、函数、结构体等**元素的名称**。

```c
void function();
int love;
```
上述的`function`和`love`都是标识符。
## 字面量(literal)
>表达源代码中一个**固定值**的表示法。

```c
int n = 0;
char c = 'a';
const char* s = "hello";
```
- `0`就是一个数值字面量
- `a`是一个字符字面量
- `hello`是一个字符串字面量

# 控制结构
## 顺序
> 顺序是程序执行最基础的控制结构。程序默认都是顺序执行的，从上到下执行给定代码

```c
int main()
{
	int a = 0;
	a = a+2;//a先被赋值为0再+2
	a = 3;//a被赋值为3
	printf("%d\n",a);//输出a
}
```
上面的代码是顺序执行的
- 先执行第一个赋值
- 再执行加法
- 再执行赋值
- 最后输出然后退出程序
## 分支
>当条件成立时执行分支下的代码，如果没有分支的条件成立就执行else中的代码。
### if - else 结构
```c
if(condition)
{
	//代码
}
else if(condition)
{
	//代码
}
else
{
	//代码
}
```

#### 组成部分
- if(condition)
	- 分支首部
- {}
	- 分支体

### switch - case结构
```c
switch (expression)
{
	case 情况:
		break;
	case 情况2:
		break;
	...
}
```

`switch case`的`case`中如果没有break将会一直执行下去

```c
switch (expression)
{
	case 情况:
		代码;
	case 情况2:
		break;
	...
}
```
上面这种情况会先执行情况1中的代码然后直接执行情况2的代码（**即使情况二中的条件不成立**）
## 循环
>当条件成立时一直执行循环体中的代码

### while
```c
while(条件)
{
	
}
```
当`while`中**条件成立**时循环开始运行
- 即**为什么开始运行**
- 而*不是*为什么结束运行


### for
```c
for(代码区;条件;代码区)
{

}
```
当`for`中条件成立时运行，代码区一般用来声明计数器变量。


### do - while
```c
do
{

}
while(条件);
```
先执行循环体中的代码，再判断是否继续执行循环，`while`中的条件依然是**开始循环的条件**

# 函数调用
>在调用函数时，会跳转到函数中的内容进行执行，执行完毕后再跳转回调用函数的地方

```c
void function()
{
	statement1;
	statement2;
	statement3;
	statement4;
	statement5;
	statement6;
}
void main()
{
	statement1;
	statement2;
	statement3;
	
	function();
	
	statement4;
	statement5;
	statement6;
}
//在执行时会变成
main:
	main::statement1;
	main::statement2;
	main::statement3;
//跳入function中
function:
	function::statement1;
	function::statement2;
	function::statement3;
	function::statement4;
	function::statement5;
	function::statement6;
//回到main函数中继续执行未完成的操作
main:
	main::statement4;
	main::statement5;
	main::statement6;
```

## 嵌套调用
>函数可以进行嵌套调用，即在函数内可以调用其他函数，在函数调用时也可以使用其他函数的结果作为参数调用
```c
int get2()
{
	return 2;
}
int function(int value)
{
	return value + get2() + get2();
}
void main()
{
	function(get2());
}

//先执行get2()获取2并作为参数传入function
//进入function
//执行两次get2(),并将他们和传入的参数加起来
//退出到main中
```

# 作用域
>作用域是变量以及函数的有效范围，变量在变量的有效范围外不存在。且同一作用域下只能拥有一个同名变量
```c
void main()
{
	int a = 0;
	{
		int b = 0;
		//a在这里有效，因为a的作用范围还没结束
		
		int a = 0;//这个a有效，但是和上面的a不是一个a
		
		
		//b将在这里被销毁
	}
	
	//b在这里无效，因为已经不在自己的作用域内了
	for(int n = 0 ;n<10;++n)
	{
		//n只在这个循环内部有效
	}
	//n在这里无效
	
	//a将在程序结束时被销毁，变成无效变量
}
```
