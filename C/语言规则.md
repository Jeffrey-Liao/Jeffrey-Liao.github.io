# C 语言规则

# 声明和定义
## 声明
>计算机通过声明得知一个程序元素的存在（变量，函数的名称，类型（返回值类型），大小）。并为其执行某些操作，如预留内存空间。

## 定义
>计算机不仅知道上述声明的所有信息，同时知道程序元素具体的信息如变量中的值和函数的函数体。

## 举例
```c
int n; //声明
int n = 0;//定义

void function();//声明
void function()
{
	printf("love you");
}
```
在这里，`n`在声明时被计算机分配了`sizeof(int)`大小（4字节）的内存


# 语言成分
## 关键字(Keyword)
>关键字是所有C语言保留的，**具有特殊含义的词的合集**
>包括以下这些：
- 类型关键字：用于标识变量、函数返回值类型。或是某些具有特殊含义的**前缀**
	- int/long/long long/short
	- unsigned/const/static/volatile
	- double/float
	- char
	- void
	- union
	- struct
	- sizeof
	- enum
	- typedef	
- 控制结构关键词：用于定义控制结构
	- if/else/else if
	- switch/case/default
	- while/for/do/break/continue
	- return

共计34个，这里只列出常见且会被用到的关键字。

正因为此，C语言也被称为"最简单"的语言，因为只有34个关键字，是所有常用语言中最少的。

当然，这是一个入门简单，但精通极其困难的语言。就连我在我自己的网站上也只写了，`熟悉C/C++`。
## 标识符(Identifier)
>标识符是一切程序员自己定义的变量、函数、结构体等**元素的名称**。

```c
void function();
int love;
```
上述的`function`和`love`都是标识符。
## 字面量(literal)
>表达源代码中一个**固定值**的表示法。

```c
int n = 0;
char c = 'a';
const char* s = "hello";
```
- `0`就是一个数值字面量
- `a`是一个字符字面量
- `hello`是一个字符串字面量
