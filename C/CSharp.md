# C\#
介绍C#中一些特性

# 输入输出
```csharp
//输入
Console.ReadLine();

//输出
Console.WriteLine();
```
`Console`就是控制台
![](pic/Pasted%20image%2020260310135708.png)
- `ReadLine()`是从控制台读取一个数据（为string类型）
	- 所以如果需要指定类型的数据，需要进行转换
- `WriteLine()`是向控制台输出一个数据（任意类型）

## 输入数据转换
在C#中，使用对应类型+'.'就可以调用与该类型相关的操作
![](pic/Pasted%20image%2020260310140108.png)
（上图中可以取绝对值`Abs()`等）
- 我们使用`Parse()`进行转换，将字符串转换为一个`int`。
- 当然对于`double`和`float`也可以执行这个转换，同样使用`Parse()`。

## 输出格式化
当我们要输出比较复杂的输出时
```csharp
Console.WriteLine("今天的日期是"+date+"我非常开心，因为我中午吃了"+number+"个寿司。");
```

我们如果使用拼接式输出就会比较麻烦，所以我们可以使用格式化输出
```csharp
Console.WriteLine("今天的日期是{0}我非常开心，因为我中午吃了{1}个寿司。", date, number);
```

`{0}/{1}`是后面的变量的位置
# 指针
- 指针变量的内部存储的是**实际数据的地址**


# Array（数组）
```
int[] arr = new int[size];
```
- 数组是一个对象（object），且创建在**堆**上
- arr变量的本质是一个指针变量，指向堆上的数据
- **数组**这个整体的**本质就是`size`个使用相同名称的变量**
- **数组是定长**的`size`就是数组的长度

## C中的数组
```c
int arr[size];
```
C中是在变量名称后面确定数组的大小。


## 堆（Heap）和栈（Stack）
- 本质：计算机内存
- 区别：区域不同
![](pic/Pasted%20image%2020260310142854.png)
对于栈上的数据来说，他们只能访问到自己这个栈中的数据（也就是左右两个Stack中的a和b各自是独立的个体）。**修改左边的a对于右边的a没有任何影响**

但`arr`由于创建在**堆**上，所以当有人指向`arr`这个区域时，*所有拥有`arr`这个地址的变量都在操作同一个数据。*
![](pic/Pasted%20image%2020260310143235.png)
(上面这个只是示意如果两个人都指向`arr`时拥有的是同一份数据，实际情况下右边的stack获取不到左边的`arr`**指针中的地址**)

## 垃圾回收（Garbage Collection）
对于arr2，现在已经没有任何人可以访问到它（因为没有人指向它，即没有人持有它的地址），所以在系统设置的一定时间（这个时间取决于C#虚拟机）后，会被自动删除，然后分配给其他人使用。

注：**C和C++没有垃圾回收这个机制**
# Collections（容器）
## List
```
List<Type> list;
```
List是一个容器，**list变量本身也是一个指针变量**，指向堆上的某个位置
![](pic/Pasted%20image%2020260310143844.png)
`List`的`<>`中间是这个列表中每个元素的类型，可以是`int/double/float`等等。
```csharp
int[] arr;
List<int> list;
```
和数组对比就是放置类型的位置不一样。

与数组不同，`List`不是定长的，可以通过`Add()`添加一个新元素到末尾
![](pic/Pasted%20image%2020260310144405.png)
