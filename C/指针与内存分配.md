# C语言的指针
```c
int* ptr=&a;//&表示取a的地址
ptr=保存的是地址
*ptr=表示的是地址内的值
```
# C语言的函数参数传递
## 值传递
>拷贝当前变量，变为一个副本，传入函数中

## 指针传递
>传递变量的内存地址

```c
void function(Position* pos)//function::pos{201,302}
{
	pos->x = 10;
	//基于pos的地址直接修改pos地址位置所表示的值
}
void main()
{
	int a, b;
	Position pos={201,302};//main::pos
	function(&pos);
	//&pos传递pos这个变量的地址到函数中
}
```
