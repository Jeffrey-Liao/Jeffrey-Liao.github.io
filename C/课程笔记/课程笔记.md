# printf 的格式化符
>用于表示输出类型的符号。

- `%s`字符串(string)
- `%d/%ld`整数(decimal)
- `%f/%lf`小数(float)
- `%c`单个字符(character)
- `%x`十六进制数(hexadecimal)
- `%p`指针(pointer)

将打印区域后的数据，在`%`的位置，以格式化符的方式打印。
```c
int number = 0;
printf("%s",number);
```

# 常见的转义字符
>反斜杠是区别于普通字符的一个特殊标记
- `\n`：换行
- `\t`：制表
	- 0000 0000 0000
- `\b`：退格，往回挪一格
- `\r`：回到开头
- `\0`：空字符，ascii == 0的情况

# 循环的条件
>循环的条件是循环**开始的条件**，不是循环结束的条件。

>do-while循环不管怎么样，都会运行一次。
