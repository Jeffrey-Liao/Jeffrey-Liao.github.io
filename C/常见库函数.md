# 常用头文件
- `<stdio.h>`：输入输出
	- `printf`：输出数据
	- `scanf`：获取输出
- `<stdlib.h>`：常用数字和内存操作
	- `atoi`：将字符转换为整数
	- `atof`：将字符转换为实数
	- `exit`：退出程序
	- `abs`：获取当前数字的绝对值
	- `malloc`：分配一块内存空间
	- `free`：回收一块内存空间
- `<string.h>`：字符串操作
	- `strcpy`：复制字符串
	- `strcat`：拼接两个字符串
	- `strcmp`：比较两个字符串是否一致
	- `strlen`：获取字符串长度
	- `memset`：设置内存内容
	- `memcpy`：拷贝内存到指定位置

# <stdio.h>
## printf
```c
printf("hello world");//输出hello world到屏幕上

int a;
printf("数据是%d",a);//使用十进制数的方式在"数据是"后面输出a
printf("数据是%u",a);//使用无符号十进制数的方式在"数据是"后面输出a
printf("数据是%x",a);//使用十六进制数的方式在"数据是"后面输出a

double a;
printf("数据是%f",a);//使用浮点数的方式在"数据是"后面输出a
printf("数据是%.5f",a);//使用浮点数的方式，保留5位小数在"数据是"后面输出a

const char* str = "喜欢你"
printf("我%s",str);//使用字符串的方式在"我"后面输出"喜欢你"

const char* str = "喜欢你"
printf("我%p",str);//在"我"后面输出str指向的"喜"的地址
```
## scanf
>需要传入接收数据的格式，以及需要接收数据的变量的**地址**
```c
int a;
double d;
char name[12];
scanf("%d", &a);        // 整数，必须 &
scanf("%f", &d);     // 浮点数，必须 &

scanf("%c", &name[0]);    // 单个字符，需要 &

scanf("%s", name);        
// 字符串，因为字符串本身是数组，数组在传入函数时会退化成指针，所以直接传入就可以
```
# <stdlib.h>
##  atoi
```c
const char* number = "123"
int a = atoi(number);
//a中的值为123

const char* negative = "-123"
a = atoi(negative)
//a中的值为-123

const char* error = "123adb"
a = atoi(error)
//a中的值为0,因为无法转换
```
## atof
```c
const char* number = "1.023"
double a = atof(number);
//a中的值为1.023

const char* negative = "-1.023"
a = atof(negative)
//a中的值为-1.023

const char* error = "1.23adb"
a = atof(error)
//a中的值为0,因为无法转换
```

## malloc/free
```c
int* me = (int*)malloc(sizeof(int))
//分配一个4字节的内存，转换为int类型的指针，然后给me，让me指向刚刚分配的数据

free(me);
//回收刚刚的内存
```
# <string.h>
## strcpy
```c
const char* str = "hello"
char new[5];
strcpy(new, str);
//将str复制到new中，将new中的内容修改为{'H','e','l','l','o'}
```

## strcat
```c
const char* str = "Love You"
char new[12]="I ";
strcat(new, str);
//将Love You拼接到I后面，new中变为I Love You
```

## strcmp
```c
const char* str = "Love You"
const char* str2 = "Love You"

int result = strcmp(str,str2);
//result为0

strcmp("abc", "abd")  → -1    // 'c'(99) < 'd'(100)
strcmp("abd", "abc")  →  1    // 'd' > 'c'
//字典序a大于b时返回1
//字典序b大于a时返回-1
```

## strlen
```c
int a = strlen("bxy");
//a为3
```

## memset
```C
void *memset(void *ptr, int value, size_t num);
```
- `ptr`：要填充的内存块指针
- `value`：要设置的值（会被转换为 unsigned char）
- `num`：要设置的字节数
```C
int* ptr = (int*) malloc(sizeof(int)*10);
memset(ptr,0,sizeof(int)*10);//将40字节的内存区域全部设置为0
ptr[0] == 0;//ptr中的所有元素现在都是0
free(ptr);
```
