# 进制转换
你在计算机学习的过程中，**二进制和十六进制**都是很常见的。但是你呢，可能之前没有接触过（这也很正常），所以这一节就告诉你如何转换进制。

## 二进制(bin)
所有在计算机的数据、代码、指令都是一个二进制数，所以任何的字母、图片什么的**最终都是一个二进制数**。

十进制转换为二进制的方法很简单
### 整数
#### 方法一 标准转换法
- 将给定数除以2，取余数，然后将最低位排在最前面

| 原数字 | 余数  |
| --- | --- |
| 25  | 1   |
| 12  | 0   |
| 6   | 0   |
| 3   | 1   |
| 1   | 1   |
- 结果：11001


#### 方法二 凑整法
- 凑整法，将数字拆解成$2^n+2^m+...+1(如果是偶数就不+1)$的形式
- $25=16+8+1=2^{5}+2^{4}+1= 1\:1001$
	- 将对应的n次方的位置写成1
- $26=16+8+2 = 1\:1010$

这个方法可以用来**手算二进制**，给你的手拿出来，从右边大拇指往左数
右手：1,2,4,8,16        左手：32,64,128,256,512
结合草稿纸可以快速算出很多二进制数😊

### 小数
小数等到了数据类型的`float`处再跟你讲
你先有个概念，小数是使用$a*2^n$的方式表示的，在存储的时候只存储$n$和$a$的值

### 正负数
二进制数的负数是由最高位表示的，第一个位是`0`就是正数，第一个位是`1`就是负数

但是，你是不是觉得1是`0001`-1是`1001`?

**戳辣！！！！！！！！！！！**😁

这样会出现一个严重的问题，叫做`-0`
即`1000`和`0000`。
诶，0怎么有两种？这不对吧

所以实际上采取的方法叫做取反补1法
即翻转所有位（原先是0变成1,1变成0），并在末尾加上1
$-1 = 0001 \to 1110+1 = 1111$
$0 =0000\to 1111+1 = 1\: 0000= 0000$（这个1是溢出的，正常情况下会被舍弃，只保留我们限定的大小，这里限定的大小是4位）

## 十六进制(hex)

| 十进制 | 十六进制 |      |
| --- | ---- | ---- |
| 1   | 1    | 0001 |
| 2   | 2    | 0010 |
| 3   | 3    | 0011 |
| 4   | 4    | 0100 |
| 5   | 5    | 0101 |
| 6   | 6    | 0110 |
| 7   | 7    | 0111 |
| 8   | 8    | 1000 |
| 9   | 9    | 1001 |
| 10  | A    | 1010 |
| 11  | B    | 1011 |
| 12  | C    | 1100 |
| 13  | D    | 1101 |
| 14  | E    | 1110 |
| 15  | F    | 1111 |
(这里最高位是1并不代表它是负数，十六进制数中没有正负数，他把数据只看出一个数据，没有意义)
#### 如何和二进制转化
1. 将二进制数字按照四位分开，如果不足四位就在前面补0
	- $25=0001\:1001$
	- $78 = 0100\:1110$
2. 然后将两个部分分别进行转换
	- $0001 \to 1,\: 1001\to 9 = 19(hex)$
	- $0011\to4,1110\to E=4E(hex)$

# 存储单位
$位bit<字节byte<KB\:KiloByte<MB\:MegaByte<GB\:GigaByte$
常见的是**位**和**字节**
0000 0000（八个位） 是一个**字节**
字节是编程中的**常用最小单位**，位虽然说更小，但是一般用的较少。

ISO国际标准化委员会存储单位转换

| 单位              | 转换             |
| --------------- | -------------- |
| 1 B             | 8 bits         |
| 1 KB            | 1000 B         |
| ***1 Kib(小写)*** | ***1024 B***   |
| 1 MB            | 1000 KB        |
| ***1 Mib***     | ***1024 Kib*** |
| 1 GB            | 1000 MB        |
| ***1 Gib***     | ***1024 Mib*** |
| 1 TB            | 1000 GB        |
| ***1 Tib***     | ***1024 Gib*** |
| 1 PB            | 1000 TB        |
| ***1 Pib***     | ***1024 Tib*** |
| 1 EB            | 1000 PB        |
| ***1 Eib***           | ***1024 Pib***       |
Ok, 这里你可能要问了，MB，KB我见过，这个Kib是个什么鬼东西？
那么，我就要介绍一下ISO的大缺大德了。
本来数据的转换都是1-1024，因为二进制转换，两个数据单位之间相差$2^n$。
但是，ISO（国际标准化组织）觉得什么都是1024倍的转换不够标准化，所以考虑到大部分的国际标准（米，毫升）等都是10基础进位的，所以就改成了1000而不是1024。

但是原有的规则程序员之间已经用了很久了，所以就出了一个什么ib的单位继续表示原来的进位方式。

这种1比1000和1比1024的转换在你学习的时候都可能出现，所以这边就把两个都列出来了

# 现代计算机
- 现代计算机由三部分组成
	1. 硬件(CPU,内存,IO控制器等)
	2. 操作系统
	3. 软件


## 硬件
计算机硬件最**核心**的是CPU


### 1. CPU的架构分类
CPU一般分类依照**指令集**分类。指令集指CPU使用的指令列表，常见的有两种：
- x86/x64(复杂指令集CISC)
- arm(精简指令集RISC)



#### x86/x64
>属于复杂指令集，即一个指令可能可以完成一系列简单操作

目前大多数电脑使用x86/x64架构，笔记本大部分使用x86/x64，台式机电脑99%以上都是。

x64是x86的升级版本，x86的最大寻址范围是$[0,2^{32}-1]$（4个字节），x64扩充到了$[0,2^{64}-1]$（8个字节）。[（如果忘了什么是字节，点这个）](#存储单位)

常见的x64芯片制造商为 Intel（英特尔）和AMD（美国半导体公司）


#### ARM
>属于精简指令集，指令多与简单操作绑定，某些在复杂指令集中的操作需要自行构建。

***所以这就是为什么在ARM上的Windows无法运行某些应用，因为指令集不同，某些指令缺少***

苹果公司目前的全部最新产品都是ARM芯片，目前市面主流手机品牌也都采用ARM芯片。

- 优势：
	- 相较于x86/64的功耗较低，完成相同任务消耗的能量较少。
	- 由于指令集较为简单，有更好的开发拓展性


目前最新的ARM芯片的寻址范围也更新到了8个字节(64位)，但是某些工业用的低端产品仍然使用4字节甚至2字节的寻址大小。

### 2. CPU的组成
CPU主要由以下部分组成：
- **CPU核心**
	- **ALU（运算器）**
		- 用于进行数学计算
	- **寄存器**
		- 暂存指令或者数据
	- **二级，一级缓存**
		- 暂存暂时需求不大的数据，需要时会进入寄存器
	- **中断控制器**
		- 你知道这个东西在就行了
	- **CU（控制器）**
		- 执行指令操作
- **三级缓存**
	- 暂存优先级低于一二级缓存需求的数据
- **总线**
	- **数据总线**
		- 从计算机的其他部分接受数据（如内存或者IO控制器）
	- **控制（指令）总线**
		- 传递CPU控制指令，操作原件工作
	- **地址总线**
		- 传递数据/指令在内存上的地址（指针部分会详细讲解）
- I**O控制器（部分CPU**）
	- 有的现代CPU如AMD系列的CPU会把IO控制器作为一个部分集成在CPU中。
		- 优点是可以以更高的效率与IO设备（如鼠标，键盘，耳机等）通信
		- 缺点是这个也导致如果IO控制器损坏整个CPU都会损坏。一般IO控制器分离设计的CPU的IO控制器芯片都很便宜

### 3. CPU 的架构
#### 冯·诺依曼架构
（请输入文本）
![[Pasted image 20260108184836.png]]
```
输入->CPU(的存储，如寄存器)->输出
```
不区分指令、数据、寻址。**全部统一存储在CPU的一个共享的内存空间中**。CPU根据操作需要转换数据的含义（前面就说了所有计算机中的数据、指令其实都是二进制数）。

且输入输出是单向通信

#### 哈佛架构
```
	   ALU(计算单元)
			↕️
数据存储<->控制器<->指令存储
			↕️
		 输入输出
```
哈佛架构将数据和指令的存储线分开，分别存储指令和数据。当CPU的计算单元需要使用时通过控制器读取指令或者数据。
且哈佛结构可以提前缓存下一条指令，**使执行效率大幅提高**（指令流水线的雏形，这个等后面跟你说）


>**当今CPU采用的是冯·诺依曼-哈弗混合结构**


### 4. CPU的作用
- **执行计算机指令完成运算**（下面的代码我写着装逼的，你不用学，mov和add都是x86/64芯片的CPU指令）
```asm
mov eax 2 将2移动到eax寄存器中
add eax 10 将eax中的值加10并保存在eax中(12)
```
- **协调各个硬件组件工作**
	- 比方说你放音乐，CPU收到软件的指令后将音乐的开始地址发送到声卡（也是一个芯片）的缓冲区，然后声卡操作扬声器播放缓存中的音频。
	- 玩游戏的时候，CPU将游戏的渲染任务交给GPU，且协调GPU与屏幕控制器让GPU渲染出的画面可以出现在屏幕上

### 5. 内存（RAM）
Random Access Memory
内存是一种**易失存储器**。
> 易失存储器在断电后，会**清空**内部存放的**所有数据**

所以在电脑的运行过程可以看成：
- 开机（通电）
- 将硬盘上的操作系统内核加载到内存里
- ！**运行操作系统**
- ！**运行程序1**
- 从硬盘上加载应用程序1到内存里
- @关闭程序1
- ！**运行程序2**
- 从硬盘上加载应用程序1到内存里（如果运气好的话，会覆盖程序1刚刚的内存）
- @关闭程序2
- @关闭操作系统
- 关机（断电）
- 此时内存上的所有数据全部被清空，里面没有任何数据。

因为数据在内存（固态硬盘也是）中存储的方式是按照：
- 电压高：1
- 电压低：0

所以当断电后，电压为0，数据也全部都消失了

### 6. IO控制器
又叫南桥（southern bridge， 是的，它的英文真是南桥），一般和CPU分开。其用于**和CPU配合控制外围**（peripheral）设备。

因为CPU是很忙的，所以有些操作并不是CPU亲力亲为（公司CEO）。所以南桥（秘书）就会协调其他**外围芯片**（它们也有计算能力，只是和CPU比很弱，但是可以**处理专项问题**）。

比方说音乐播放，CPU会把播放开始的位置和文件地址交给南桥，南桥通知声卡（处理音频的专项芯片）处理音频信息并持续播放。
这样CPU就可以把宝贵的资源用在其他地方，而不是一直盯着一首歌放完没有。

### 7. 外存(Disk)
外存是一种**非易失性存储（永固型存储器）**
>非易失性存储在断电后**依然会保持数据有效**很长时间（不是永远，一般是几年或者几十年），直到外力破坏或人为损毁

常见的外存（以下说的生存期都是拔了电的）：
- 固态硬盘
	- ***读/写速度***：目前常用存储介质中速度最快的
	- ***作用***：民用领域存储数据和应用软件，商业上用作大型数据库或者数据仓库的缓冲盘。
	- ***数据生存期***：**1～2（民用）/5～10（商用）年**
- 机械硬盘（磁盘）
	- ***读/写速度***：慢于固态硬盘，但快于下面几个
	- ***作用***：冷备份数据，或者长期存储数据用
	- **原理**：对一个高速旋转的可充磁的碟片上的某个区域进行磁化。有磁为`1`无磁为`0`
	- ***数据生存期***：**3～10年（无磁场干扰）**
- 磁带（对，这东西现在还在用）
	- ***读/写速度***：读很慢，写也不算快
	- ***作用***：常用于企业数据冷备份，抗干扰能力较强，保存数据时间最久
	- ***数据生存期***：**15～30 年**
- 纸带
	- 非常原始的计算机使用的存储介质，研究人员在纸带上打孔和不打孔表示1和0。这玩意在我生出来之前就不用了
	- 但是要记住世界上第一台通用（这个定语很重要）计算机ENIAC诞生于**1946年2月14日**
- 软盘
	- 也是一个在我生出来之前就废弃的东西
	- 不过现在日本还在用...


### 8. 存储介质速度天梯榜
CPU

- 一级缓存（几K）
- 二级缓存（几十K）

## 操作系统

### 概述
软件一般**运行在操作系统**上，操作系统负责***提供底层硬件与使用者沟通的渠道（接口）***。使得复杂的硬件操作在使用者看来简单易懂（虽然说也不完全很易懂）。

所以，这也是为什么在Windows上的软件(.exe)在Linux(.out)上不能运行。但是，同一台电脑可以安装Windows系统也可以安装Linux系统。

## 软件
一个包含着若干个CPU指令和数据的文件。这些指令可以被操作系统发送给CPU使CPU按照文件中的指令和数据工作。

软件在未被启动的时候是放在外存上，只有在运行时才会被加载到内存上。
