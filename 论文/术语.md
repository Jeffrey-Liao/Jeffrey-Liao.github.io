# 测站水位
> 指**某个特定的水位观测站（或水文站）所测量到的当地河流、湖泊、水库等水体的自由水面海拔高度（或相对于某个固定基面的高度）。**

## 表示方式
- **绝对高程（海拔）**：以黄海、渤海等平均海平面作为零点。例如：“该测站水位为52.30米”，意思就是水面海拔52.30米。这种方式便于不同河流、不同地区之间对比。
- **相对水位（假定基面）**：在某个河段，为了方便观测涨落变化，会人为设定一个“零点”（通常低于河底）。例如“水位2米”，表示水面比人为零点高出2米。这种方式只反映本测站的水深变化。

## 关键值
- **枯水位**：长期干旱时的低水位。
- **警戒水位**：可能发生险情，需要加强警惕的水位。
- **保证水位**：堤防能够安全防御的最高水位（接近或达到堤顶）。
- **历史最高/最低水位**：该测站有记录以来的极值。

# 坝前水位
>**水坝上游、紧挨着大坝拦水面（坝轴线处）的水位高度**。

## 作用
1. **决定大坝安全**：坝前水位不能超过设计时确定的“正常蓄水位”或“防洪限制水位”。如果水位失控上涨，会对大坝结构造成压力，甚至导致漫坝或溃坝。
2. **反映水库蓄水量**：每个水库都有“水位-库容曲线”。知道了坝前水位，就可以通过查这条曲线，准确地知道水库里现在存了多少亿立方米的水。

## 关键值
- **死水位**：允许水库消落的最低坝前水位。低于这个水位，发电机组就无法正常工作或抽不到水。
- **防洪限制水位**：汛期为了预留防洪库容，要求坝前水位不能超过的上限。
- **正常蓄水位**：非汛期或平水期，水库正常情况下能达到的最高蓄水位。此时水库蓄满，效益最大。
- **设计洪水位**：遇到大坝设计标准下的洪水时，坝前出现的最高水位（允许短暂出现）。
- **校核洪水位**：遇到极罕见、超过设计标准的洪水时，大坝能承受的极限最高水位。

# 设计防洪标准
>指工程在**正常运行**条件下，能够安全宣泄（或拦蓄）的最大洪水规模。也称为**设计洪水**。当实际洪水 **≤** 设计标准时，工程必须**绝对安全**。

# 校核防洪标准
>指在**非常特殊、极端**的条件下，工程能够**承受的极限最大洪水**。这是确保大坝不会发生溃坝的最后一道防线。也称为**校核洪水**。
- **保坝安全**。哪怕洪水超过了设计标准，大坝即使受损（比如允许漫坝、轻微破坏），也绝不能整体溃塌造成毁灭性灾难。
- 当实际洪水 ≤ 校核标准时，**大坝不允许溃坝**（可允许部分泄洪设施损毁）；当实际洪水 > 校核标准（几乎不可能遇到），大坝理论上可能失事。

# 重现期
> 指大于或等于某一量级的洪水，在很长一段时间内（通常按百年统计），**平均**每多少年出现一次。依赖于**统计资料的长度和近年气候变化**.
- **公式**：$T=\frac{1}{P}$
    - T：重现期（年）
    - P：年超越概率（即该量级洪水在任意一年中，被超过的可能性）

| 水库大坝等级                | 设计标准（正常运用）       | 校核标准（非常运用）                        | 通俗理解                           |
| --------------------- | ---------------- | --------------------------------- | ------------------------------ |
| **Ⅰ级**  <br>（如三峡、特大型） | **1000～500年** 一遇 | **10000～5000年** 一遇  <br>（或可能最大洪水） | 设计：应对千年洪水不坏。  <br>校核：应对万年洪水不垮。 |
| **Ⅱ级**  <br>（大型）      | **500～100年** 一遇  | **5000～2000年** 一遇                 | 设计：应对五百年洪水。  <br>校核：应对五千年洪水。   |
| **Ⅲ级**  <br>（中型）      | **100～50年** 一遇   | **2000～1000年** 一遇                 | 设计：应对百年洪水。  <br>校核：应对两千年洪水。    |
| **Ⅳ级**  <br>（小型）      | **50～30年** 一遇    | **500～200年** 一遇                   | 设计：应对三十年洪水。  <br>校核：应对五百年洪水。   |

# 流域面积
>指**一条河流（或一个水系）的分水线（分水岭）所包围的范围**。简单来说，就是**该流域内所有降水最终都会汇集到这条河流的出口断面的那片区域的总面积**。

## 意义
- **流域面积越大，河流的总径流量（水量）通常就越大**
- 形成的**洪水洪峰流量（洪水最高点）也越大**。
- 流域面积决定了水能资源、可供水量的上限

# 坝址以上流域面积
>指大坝所在的那个位置（坝址）作为“出口断面”，其上游所有能够自然汇水到坝前的区域面积总和。

# 支流分级
- **干流**：是水系的“主干”，相当于**树干**。
- **一级支流**：是直接**流入**干流的河流，相当于从树干上直接长出来的**一级分枝**。
- **二级支流**：是直接**流入**一级支流的河流，相当于长在一级分枝上的**二级分枝**。以此类推。

# 设计暴雨强度查算表
>确定**在特定重现期下，暴雨的雨量有多大、雨强有多猛、以及雨在时间上是如何分布的**，进而计算出需要排出的雨水流量（即设计流量）。

## 雨型分类
- **暴雨强度 (i 或 q)**：指单位时间内的降雨深度，单位通常是 **mm/min**；或者用另一个常用单位 **L/(s·hm²)**，表示单位面积上的降雨体积。它和**重现期 (T)**、**降雨历时 (t)** 紧密相关。**重现期 T 越长、降雨历时 t 越短，暴雨强度就越大**。
- **暴雨雨型**：指一场暴雨在时间上的分配模式。同样是24小时降雨100mm，是“前大后小”还是“中间集中”？雨型决定了洪峰是尖瘦还是矮胖。

## 表格计算
1. **确定重现期 T**：根据工程等级和规范确定。例如，一般城市道路取 **T=2年**，重要立交桥排水可能取 **T=5-10年**。
2. **确定降雨历时 t**：t = 地面汇流时间 + 管内流行时间。对于小面积排水，t 通常取 5-15 分钟。
3. **查表**：在T=2年、t=10分钟那一格，得到 i=1.50 mm/min。这个值就是设计依据。

# 设计暴雨雨型查算表
>**这100mm的雨，在24小时内，第5分钟下多大？第60分钟下多大？**

## 示例表格
|时段 (分钟)|累计雨量占比 (%)|该时段平均强度占比 (%)|
|---|---|---|
|0-5|5%|5%|
|5-10|8%|3%|
|10-15|15%|7%|
|15-20|30%|15%|
|20-25|55%|25% (峰值)|
|25-30|70%|15%|
|30-35|82%|12%|
|35-40|91%|9%|
|40-45|96%|5%|
|45-50|98%|2%|
|50-55|99%|1%|
|55-60|100%|1%|
## 表格计算
1. **确定总降雨量**：用T=2年、t=60分钟的强度 i=1.20 mm/min，乘以60分钟，得到总降雨量 H = 72 mm。
2. **分配峰值**：查上表，峰值出现在第20-25分钟，该时段强度占比25%。意味着这5分钟内的降雨量为 72mm × 25% = 18mm，雨强高达 3.6 mm/min，远高于平均的1.20 mm/min。
3. **应用**：将这个时间分配输入水文模型，就能计算出排水管道最危险的时刻（通常是峰值出现后的几分钟）。

# 控制流域面积
>**在水工建筑物（如大坝、水库、水文站）的特定位置（即“控制断面”）以上，能够自然汇流到该断面的整个集水区域面积**。

|术语|定义|侧重点|举例|
|---|---|---|---|
|**流域面积**|一条河流整个水系的分水线包围的总面积。|**河流水系本身的自然属性**，是固定的。|长江的流域面积约180万km²。|
|**控制流域面积**|某个**特定工程或测站**所在断面以上的汇水面积。|**工程或测站的控制范围**，取决于断面位置。|三峡大坝的控制流域面积约100万km²。|

# 设计洪水成果
>针对某一特定工程（如大坝、桥梁、堤防）和某一特定设计标准（即重现期，如百年一遇），通过规范方法计算得到的**一组完整的洪水特征数据**。

|要素|单位|含义|
|---|---|---|
|**设计洪峰流量**|m³/s|洪水过程中出现的最大瞬时流量|
|**设计洪水总量**|万m³ 或 亿m³|一场洪水从起涨到退水期间的总径流量|
|**设计洪水过程线**|m³/s ~ 时间|洪水流量随时间变化的完整曲线形状|

## 用途
- **确定大坝高度**：设计洪水位和校核洪水位直接决定坝顶高程。
- **确定泄洪设施规模**：泄洪闸、溢洪道、泄洪洞的大小，必须能安全下泄设计洪水。
- **确定调洪库容**：水库需要预留多大的空间来拦蓄洪水。
- **下游防洪评估**：分析工程泄洪后，下游河道水位是否会淹没城镇农田。

## 计算方法
|方法|适用条件|输出成果|
|---|---|---|
|**频率分析法**|有较长实测流量资料（≥30年）|设计洪峰、洪量|
|**暴雨推求洪水法**|有暴雨资料，无流量资料（最常见）|完整的洪水过程线|
|**水文模型法**|资料较好，且需考虑流域内水库、闸坝影响|更精细的过程线|
|**经验公式法（如面积指数法）**|无资料地区的初步估算|仅设计洪峰|

# 产流
> 降雨落到地面后，经过植物截留、下渗、填洼等损失后，剩下的雨水形成**径流**的过程。
>$总降雨量 = 截留 + 下渗 + 填洼 + 径流$,决定洪水的**总量**

## 分类
|产流类型|发生条件|特点|常见地区|
|---|---|---|---|
|**超渗产流**|降雨强度 > 下渗能力|雨水来不及下渗，直接在地表形成径流|干旱、半干旱地区（如西北、华北）|
|**蓄满产流**|土壤含水量达到饱和|土壤“喝饱了”，后续雨水全部变成径流|湿润地区（如长江、华南）|

## 结果
计算的结果是**净雨量**（或称有效降雨），即扣除损失后、实际参与径流形成的那部分雨水。
- **净雨量** ≤ 总降雨量
- **净雨强度**（mm/h）通常小于降雨强度

# 汇流
>**汇流**是指净雨从流域各处，沿着坡面和河网，汇集到流域出口断面的过程。决定洪水的**过程和峰值**

## 阶段
|阶段|路径|速度|时间尺度|
|---|---|---|---|
|**坡面汇流**|从山坡表面流入附近的小沟、小溪|较慢（几十米到几百米/小时）|几分钟到几十分钟|
|**河网汇流**|从支流到干流，再到流域出口|较快（几米/秒）|几小时到几天|
## 结果
>**洪水过程线**——出口断面流量随时间的变化曲线
- **净雨强度越大、汇流时间越短** → 洪峰越高、过程线越尖瘦（山区河流特点）。
- **净雨强度较小、汇流时间长** → 洪峰较低、过程线越矮胖（平原河流特点）。

# 汇流时间 $τ$
- **流域汇流时间** $τ$（也称流域滞时）：最远一滴水从流域边界流到出口所需的时间。
- **物理意义**：它决定了洪峰出现在降雨之后的**滞后时间**，也影响**洪峰是被“削平”还是被“叠加”**。

# 设计断面洪峰流量
>**在指定的设计标准（即重现期）下，某一特定河流断面（如拟建大桥的位置、水库大坝坝址、或防洪堤所在的断面）处，可能出现的*最大瞬时流量*。**

|术语|含义|在本概念中的作用|
|---|---|---|
|**设计**|对应一个选定的**重现期**（如100年、50年）|决定了风险标准，即“多大级别的洪水”。|
|**断面**|河流上**一个特定的横截面位置**|这是成果的**空间属性**。不同位置（上游 vs 下游）的洪峰流量不同。|
|**洪峰**|洪水过程中**最高的那个瞬时流量**|这是成果的**时间属性**，是洪水的最大破坏力点。|
|**流量**|单位时间内通过断面的水体体积（m³/s）|这是成果的**数值**。|
- **上游断面**：控制流域面积小，汇流时间短，但洪峰流量**较小**（因为汇水范围小），但涨落**陡峭**。
- **下游断面**：控制流域面积大，汇集了沿途所有支流的水，洪峰流量**大得多**，但涨落相对**平缓**。

# 左右岸地表高程
>站在河流上游面向下游方向（即顺水流方向看），左侧和右侧岸边地面（或堤防顶部、滩地）相对于某个基准面（如黄海高程系）的海拔高度。
- **堤顶高程**：堤防顶面的高度。这是防洪的生命线。
- **滩地高程**：河道与堤防之间滩地（可能种庄稼、长树）的高度。
- **岸坡高程**：从水边到滩地或堤脚的斜坡高度。
- **护岸/挡墙顶高程**：人工建筑物的顶部高度。

| **设计断面**       | 我们关心的、位于河道上的**一个具体横截面位置**。比如，计划建大坝的位置、建桥的位置、或者设水文站的位置。        | 河道上的**一个“点”**。            |
