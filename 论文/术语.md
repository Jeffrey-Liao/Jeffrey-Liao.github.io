# 短期中期长期
## 短期预报（1-3天）
- **核心目标**：主要为**防洪调度、航运安全**提供精准决策支持。
- **技术方法**：目前主流是通过**气象水文耦合模型**和**深度学习**进行精细化模拟。
- **精度指标**：预报精度较高，**3日短期预报误差可控制在0.2米内**，准确率可达**80%以上**。在极端天气下，耦合物理模型与深度学习的模型（如HEC-LSTM）能将预测精度（RMSE）显著提升**25%-46%。

## 中期预报（3-15天）
- 核心目标：服务于水库优化调度、发电计划制定和汛限水位动态控制。
- 技术方法：利用数值天气预报（NWP） 驱动水文模型，实现“气象-水文”一体化预报。
- 精度指标：7日预报准确率可达80%以上，误差通常控制在0.5米以内。对于河道断面流量，72小时预报合格率可达乙级标准（80%以上）。

## 中长期趋势预报（月度/季度）
- 核心目标：指导水资源分配、农业灌溉及水库蓄放水策略。
- 技术方法：多采用人工智能（BP神经网络、LSTM） 结合径流特性进行分段预报，或者利用气候模式进行趋势判断。
- 精度指标：主要判断趋势（偏丰/偏枯），绝对数值误差相对较大。分段预报方法（区分枯水期和丰水期）相比全年统算，可将平均绝对百分比误差（MAPE）优化25%以上。预见期可达6个月，支持日、旬、月尺度输出。

# 来水预报
> 针对江河、水库或流域未来一段时间内**径流量（流量、水位）**的预测。不同于常规天气预报，它更关注**地表水汇流后的总量、过程和趋势**。

| 预见期           | 主要用途         | 常用方法             | 典型精度           |
| ------------- | ------------ | ---------------- | -------------- |
| **短期**（1-3天）  | 洪水预警、发电调度、航运 | 水文模型 + 实测降雨/气象预报 | 流量误差≤20%       |
| **中期**（4-15天） | 水库蓄放水计划、中调计划 | 气象集合预报 + 水文模型    | 趋势较准，总量误差30%左右 |
| **长期**（月/季/年） | 水资源配置、蓄水策略   | 历史同潮类比、气候模式、AI   | 主要判断丰枯趋势       |

# 测站水位
> 指**某个特定的水位观测站（或水文站）所测量到的当地河流、湖泊、水库等水体的自由水面海拔高度（或相对于某个固定基面的高度）。**

## 表示方式
- **绝对高程（海拔）**：以黄海、渤海等平均海平面作为零点。例如：“该测站水位为52.30米”，意思就是水面海拔52.30米。这种方式便于不同河流、不同地区之间对比。
- **相对水位（假定基面）**：在某个河段，为了方便观测涨落变化，会人为设定一个“零点”（通常低于河底）。例如“水位2米”，表示水面比人为零点高出2米。这种方式只反映本测站的水深变化。

## 关键值
- **枯水位**：长期干旱时的低水位。
- **警戒水位**：可能发生险情，需要加强警惕的水位。
- **保证水位**：堤防能够安全防御的最高水位（接近或达到堤顶）。
- **历史最高/最低水位**：该测站有记录以来的极值。

# 坝前水位
>**水坝上游、紧挨着大坝拦水面（坝轴线处）的水位高度**。

## 作用
1. **决定大坝安全**：坝前水位不能超过设计时确定的“正常蓄水位”或“防洪限制水位”。如果水位失控上涨，会对大坝结构造成压力，甚至导致漫坝或溃坝。
2. **反映水库蓄水量**：每个水库都有“水位-库容曲线”。知道了坝前水位，就可以通过查这条曲线，准确地知道水库里现在存了多少亿立方米的水。

## 关键值
- **死水位**：允许水库消落的最低坝前水位。低于这个水位，发电机组就无法正常工作或抽不到水。
- **防洪限制水位**：汛期为了预留防洪库容，要求坝前水位不能超过的上限。
- **正常蓄水位**：非汛期或平水期，水库正常情况下能达到的最高蓄水位。此时水库蓄满，效益最大。
- **设计洪水位**：遇到大坝设计标准下的洪水时，坝前出现的最高水位（允许短暂出现）。
- **校核洪水位**：遇到极罕见、超过设计标准的洪水时，大坝能承受的极限最高水位。

# 设计防洪标准
>指工程在**正常运行**条件下，能够安全宣泄（或拦蓄）的最大洪水规模。也称为**设计洪水**。当实际洪水 **≤** 设计标准时，工程必须**绝对安全**。

# 校核防洪标准
>指在**非常特殊、极端**的条件下，工程能够**承受的极限最大洪水**。这是确保大坝不会发生溃坝的最后一道防线。也称为**校核洪水**。
- **保坝安全**。哪怕洪水超过了设计标准，大坝即使受损（比如允许漫坝、轻微破坏），也绝不能整体溃塌造成毁灭性灾难。
- 当实际洪水 ≤ 校核标准时，**大坝不允许溃坝**（可允许部分泄洪设施损毁）；当实际洪水 > 校核标准（几乎不可能遇到），大坝理论上可能失事。


# 流域面积
>指**一条河流（或一个水系）的分水线（分水岭）所包围的范围**。简单来说，就是**该流域内所有降水最终都会汇集到这条河流的出口断面的那片区域的总面积**。

## 意义
- **流域面积越大，河流的总径流量（水量）通常就越大**
- 形成的**洪水洪峰流量（洪水最高点）也越大**。
- 流域面积决定了水能资源、可供水量的上限

# 坝址以上流域面积
>指大坝所在的那个位置（坝址）作为“出口断面”，其上游所有能够自然汇水到坝前的区域面积总和。

# 支流分级
- **干流**：是水系的“主干”，相当于**树干**。
- **一级支流**：是直接**流入**干流的河流，相当于从树干上直接长出来的**一级分枝**。
- **二级支流**：是直接**流入**一级支流的河流，相当于长在一级分枝上的**二级分枝**。以此类推。

# 设计暴雨强度查算表
>确定**在特定重现期下，暴雨的雨量有多大、雨强有多猛、以及雨在时间上是如何分布的**，进而计算出需要排出的雨水流量（即设计流量）。

## 雨型分类
- **暴雨强度 (i 或 q)**：指单位时间内的降雨深度，单位通常是 **mm/min**；或者用另一个常用单位 **L/(s·hm²)**，表示单位面积上的降雨体积。它和**重现期 (T)**、**降雨历时 (t)** 紧密相关。**重现期 T 越长、降雨历时 t 越短，暴雨强度就越大**。
- **暴雨雨型**：指一场暴雨在时间上的分配模式。同样是24小时降雨100mm，是“前大后小”还是“中间集中”？雨型决定了洪峰是尖瘦还是矮胖。

## 表格计算
1. **确定重现期 T**：根据工程等级和规范确定。例如，一般城市道路取 **T=2年**，重要立交桥排水可能取 **T=5-10年**。
2. **确定降雨历时 t**：t = 地面汇流时间 + 管内流行时间。对于小面积排水，t 通常取 5-15 分钟。
3. **查表**：在T=2年、t=10分钟那一格，得到 i=1.50 mm/min。这个值就是设计依据。

# 设计暴雨雨型查算表
>**这100mm的雨，在24小时内，第5分钟下多大？第60分钟下多大？**

## 示例表格
|时段 (分钟)|累计雨量占比 (%)|该时段平均强度占比 (%)|
|---|---|---|
|0-5|5%|5%|
|5-10|8%|3%|
|10-15|15%|7%|
|15-20|30%|15%|
|20-25|55%|25% (峰值)|
|25-30|70%|15%|
|30-35|82%|12%|
|35-40|91%|9%|
|40-45|96%|5%|
|45-50|98%|2%|
|50-55|99%|1%|
|55-60|100%|1%|
## 表格计算
1. **确定总降雨量**：用T=2年、t=60分钟的强度 i=1.20 mm/min，乘以60分钟，得到总降雨量 H = 72 mm。
2. **分配峰值**：查上表，峰值出现在第20-25分钟，该时段强度占比25%。意味着这5分钟内的降雨量为 72mm × 25% = 18mm，雨强高达 3.6 mm/min，远高于平均的1.20 mm/min。
3. **应用**：将这个时间分配输入水文模型，就能计算出排水管道最危险的时刻（通常是峰值出现后的几分钟）。

# 控制流域面积
>**在水工建筑物（如大坝、水库、水文站）的特定位置（即“控制断面”）以上，能够自然汇流到该断面的整个集水区域面积**。

|术语|定义|侧重点|举例|
|---|---|---|---|
|**流域面积**|一条河流整个水系的分水线包围的总面积。|**河流水系本身的自然属性**，是固定的。|长江的流域面积约180万km²。|
|**控制流域面积**|某个**特定工程或测站**所在断面以上的汇水面积。|**工程或测站的控制范围**，取决于断面位置。|三峡大坝的控制流域面积约100万km²。|

# 设计洪水成果
>针对某一特定工程（如大坝、桥梁、堤防）和某一特定设计标准（即重现期，如百年一遇），通过规范方法计算得到的**一组完整的洪水特征数据**。

|要素|单位|含义|
|---|---|---|
|**设计洪峰流量**|m³/s|洪水过程中出现的最大瞬时流量|
|**设计洪水总量**|万m³ 或 亿m³|一场洪水从起涨到退水期间的总径流量|
|**设计洪水过程线**|m³/s ~ 时间|洪水流量随时间变化的完整曲线形状|

## 用途
- **确定大坝高度**：设计洪水位和校核洪水位直接决定坝顶高程。
- **确定泄洪设施规模**：泄洪闸、溢洪道、泄洪洞的大小，必须能安全下泄设计洪水。
- **确定调洪库容**：水库需要预留多大的空间来拦蓄洪水。
- **下游防洪评估**：分析工程泄洪后，下游河道水位是否会淹没城镇农田。

## 计算方法
|方法|适用条件|输出成果|
|---|---|---|
|**频率分析法**|有较长实测流量资料（≥30年）|设计洪峰、洪量|
|**暴雨推求洪水法**|有暴雨资料，无流量资料（最常见）|完整的洪水过程线|
|**水文模型法**|资料较好，且需考虑流域内水库、闸坝影响|更精细的过程线|
|**经验公式法（如面积指数法）**|无资料地区的初步估算|仅设计洪峰|


# 汇流时间 $τ$
- **流域汇流时间** $τ$（也称流域滞时）：最远一滴水从流域边界流到出口所需的时间。
- **物理意义**：它决定了洪峰出现在降雨之后的**滞后时间**，也影响**洪峰是被“削平”还是被“叠加”**。

# 设计断面洪峰流量
>**在指定的设计标准（即重现期）下，某一特定河流断面（如拟建大桥的位置、水库大坝坝址、或防洪堤所在的断面）处，可能出现的*最大瞬时流量*。**

|术语|含义|在本概念中的作用|
|---|---|---|
|**设计**|对应一个选定的**重现期**（如100年、50年）|决定了风险标准，即“多大级别的洪水”。|
|**断面**|河流上**一个特定的横截面位置**|这是成果的**空间属性**。不同位置（上游 vs 下游）的洪峰流量不同。|
|**洪峰**|洪水过程中**最高的那个瞬时流量**|这是成果的**时间属性**，是洪水的最大破坏力点。|
|**流量**|单位时间内通过断面的水体体积（m³/s）|这是成果的**数值**。|
- **上游断面**：控制流域面积小，汇流时间短，但洪峰流量**较小**（因为汇水范围小），但涨落**陡峭**。
- **下游断面**：控制流域面积大，汇集了沿途所有支流的水，洪峰流量**大得多**，但涨落相对**平缓**。

# 左右岸地表高程
>站在河流上游面向下游方向（即顺水流方向看），左侧和右侧岸边地面（或堤防顶部、滩地）相对于某个基准面（如黄海高程系）的海拔高度。
- **堤顶高程**：堤防顶面的高度。这是防洪的生命线。
- **滩地高程**：河道与堤防之间滩地（可能种庄稼、长树）的高度。
- **岸坡高程**：从水边到滩地或堤脚的斜坡高度。
- **护岸/挡墙顶高程**：人工建筑物的顶部高度。

# 设计断面控制流域面积

| 术语             | 定义                                                            | 通俗理解                      |
| -------------- | ------------------------------------------------------------- | ------------------------- |
| **设计断面**       | 我们关心的、位于河道上的**一个具体横截面位置**。比如，计划建大坝的位置、建桥的位置、或者设水文站的位置。        | 河道上的**一个“点”**。            |
| **设计断面控制流域面积** | 以**设计断面**为下游边界，其上游所有能够自然汇流到该断面的**那部分流域面积**。这是“流域面积”的一个**子集**。 | 这个**“点”** 上游的**“专属责任田”**。 |
# P-Ⅲ型分布曲线适线
> 通过一条理论曲线（P-Ⅲ型曲线），去“拟合”你手上有限的历史水文数据点，从而推断出未来可能发生的、极低概率（如百年一遇、千年一遇）的水文数值。由**三个参数**决定：**均值 $\bar{x}$**、**变差系数 $C_v$**、**偏态系数 $C_s$**。使得曲线与点据之间的总体偏差最小。这个过程就是**适线**。

1. **从“经验”到“理论”**：把你有限的实测数据点，在概率纸上点绘出来（这些点连起来是一条锯齿状的经验频率曲线）。
2. **用理论曲线拟合**：假设这些数据服从P-Ⅲ型分布，然后通过适线，找到一条最平滑、最能代表这些点趋势的理论P-Ⅲ型曲线。
3. **向外推求**：沿着这条平滑的理论曲线向外延伸，就可以读取到超出实测资料年限的、极低频率的设计洪水值。
## 输出结果：不同频率洪水成果
>针对同一个河流断面（如大坝坝址、桥位），通过P-Ⅲ型曲线适线等统计方法，计算出一系列不同“重现期”（即不同频率）所对应的设计洪水特征值。

|要素|单位|含义|与不同频率的关系|
|---|---|---|---|
|**洪峰流量** $Q_m$|m³/s|洪水过程中最高的瞬时流量|频率越小（重现期越长），洪峰流量越大。|
|**洪水总量** $W$|万m³ 或 亿m³|一场洪水从起涨到退水期间的总径流量|同样，频率越小，洪水总量越大。|
|**洪水过程线**|m³/s ~ 时间|流量随时间变化的完整曲线形状|频率不同，过程线的形状（胖瘦、尖缓）也会不同。|
### 表现形式
1. 频率-流量关系表（最常用）
	- 通常包括**重现期 T**、**频率 P** 和 **设计洪峰流量 $Q_m$**。
2. 频率-流量关系曲线（更直观）
	- 横轴为频率 P（或重现期 T），纵轴为洪峰流量 $Q_m$，连成一条光滑曲线。

# 设计洪水过程线
>在指定的设计标准（即重现期）下，通过产流、汇流计算或洪水频率分析，得到的流经河流某一特定断面（如大坝坝址）的、完整的洪水流量随时间变化的曲线。

|要素|单位|含义|工程意义|
|---|---|---|---|
|**起涨点**|时间|洪水开始明显上涨的时刻|确定预警、开始调度的时机|
|**涨水段**|小时/天|从起涨到洪峰的过程，流量持续增加|反映洪水上涨的**陡峭程度**，影响水库需快速泄洪的压力|
|**洪峰流量** $Q_m$|m³/s|曲线上的最高点，最大瞬时流量|决定大坝、泄洪道、堤防的**最大承受能力**|
|**峰现时间**|时间|洪峰出现的具体时刻|用于洪水预报和调度决策的关键时间点|
|**退水段**|小时/天|从洪峰回落到起涨水位的过程|反映洪水**消退速度**，影响水库下游淹没时间|
|**洪水总量** $W$|万m³ 或 亿m³|过程线以下的**总面积**|决定水库需要的**防洪库容**大小|

|洪水类型|洪水过程线形状|洪水总量|对水库的影响|
|---|---|---|---|
|**尖瘦型**|涨得快、落得快，像一座尖山|较小|水库只要短时间拦住洪峰，很快就能排空，需要的**调洪库容小**。|
|**矮胖型**|涨得慢、落得慢，像一座宽缓的山丘|较大|水库需要**长时间**拦蓄大量来水，需要的**调洪库容非常大**，否则就会漫坝。|

## 如何计算
### 有实测资料地区（频率分析 + 典型放大法）
1. **选典型洪水**：从历史实测洪水中，挑选一场**对工程最不利**的洪水过程线（如峰高、量大、尖瘦型）作为“模板”。
2. **推求设计洪峰、洪量**：通过你之前学的 **P-Ⅲ型曲线适线**，得到设计标准下的设计洪峰 $Q_{mP}$ 和设计洪量 $W_P$。
3. **放大典型**：用设计值去“放大”典型洪水过程线，使其洪峰和洪量都达到设计标准。常用方法有**同倍比法**或**同频率法**。

### 无资料地区（暴雨推求法）—— 你之前学过的产汇流
1. **设计暴雨**：给定重现期，计算设计暴雨过程。
2. **产流计算**：暴雨 → 扣除损失 → 净雨过程。
3. **汇流计算**：净雨 → 单位线或等流时线 → **设计洪水过程线**。


# 同频率分段控制
>让最终得到的这条设计洪水过程线，其不同时段（如1天、3天、7天）的洪水总量，都能分别达到你通过频率分析计算出来的设计标准值。

## 核心步骤：
1. **选择典型洪水**：选一场对工程不利、峰高量大的实测洪水过程线作为“模板”。
2. **确定设计值**：通过P-Ⅲ型曲线适线（你之前了解的），计算出不同时段（如1天、3天、7天）的**设计洪量**（$W_{1天设计}$， $W_{3天设计}$， $W_{7天设计}$）。
3. **分段放大**：将洪水过程线划分为几个时段（比如7天、3天、1天），**从最长时段开始，逐段计算各自的放大倍数**，并保证下一级时段的洪量是在上一级的基础上“叠加”控制的。
# 管涌
>在高水位压力下，水强行从土壤内部的孔隙中穿过，并把土体中的细颗粒“带走”，像掏老鼠洞一样，在土体内部形成一条越来越大的渗水通道，最终导致工程溃决。

# 重力坝
>重力坝为由混凝土或石料修筑的，主要依靠坝体自重保持自身稳定的坝。其基本剖面是直角三角形，整体是由若干坝段组成。

## 分类
按其结构形式，可分为
- 实体重力坝、
- 空腹重力坝
- 宽缝重力坝;

按溢流情况，可分为
- 非溢流重力坝和
- 溢流重力坝;

按筑坝材料，可分为
- 混凝土重力坝和
- 浆砌石重力坝。

## 优点
1. 相对安全可靠,耐久性好，抵抗渗漏、洪水漫溢、地震和战争破坏能力都比较强；
2. 设计、施工技术简单，易于机械化施工；
3. 对不同的地形和地质条件适应性强，任何形状河谷都能修建重力坝，对地基条件要求相对来说不太高；
4. 在坝体中可布置引水、泄水孔口，解决发电、泄洪和施工导流等问题。

# 下垫面
>**大气层下界的表面**，即地球的固体或液体表面。

| 大类           | 具体类型         | 水文特点                |
| ------------ | ------------ | ------------------- |
| **自然下垫面**    | 森林、草地、灌木、湿地  | 截留多、下渗强、产流慢、蒸发大     |
| **农业下垫面**    | 农田、水田、旱地     | 受耕作影响，水田蓄水性强，旱地下渗中等 |
| **水体的下垫面**   | 河流、湖泊、水库、海洋  | 无截留、蒸发强烈、直接产流       |
| **城市/人工下垫面** | 混凝土、沥青、屋顶、广场 | 截留极少、下渗几乎为零、产流快、洪峰高 |
| **裸露/贫瘠下垫面** | 裸土、沙漠、岩石、冰川  | 下渗差异大（沙漠强，岩石弱），产流快  |

## 影响
### 产流
- **下渗能力**：森林、农田的下渗能力强，雨水更容易渗入土壤，减少地表径流；而水泥路面几乎不渗水，雨水立即变成地表径流。
- **截留能力**：茂密的森林冠层可以截留降雨量的 15%~30%，这些水最终被蒸发，不参与产流。

### 汇流
- **地表糙率**：森林、草地糙率大，水流速度慢，汇流时间长，洪峰被“削平”；光滑的城市路面糙率小，水流速度快，汇流时间短，洪峰尖瘦。
- **地形坡度**：坡度越陡，汇流越快；坡度平缓，汇流越慢。

### 蒸发
- **水面蒸发**：湖泊、水库蒸发量大。
- **土壤蒸发 + 植物蒸腾**：森林、农田的蒸散发总量很大，能消耗大量降水。

# 死水位和死库容
| 术语      | 定义                         |
| ------- | -------------------------- |
| **死水位** | 水库在正常运用情况下，允许消落到的**最低水位**。 |
| **死库容** | 死水位以下（库底到死水位之间）的**水库容积**。  |
- **死库容**通常被设计用来**容纳水库运行期间的泥沙淤积**，保护死水位以上的**兴利库容**（可以用的水）
- 死水位以下的水通常**不参与调节**，但在极端干旱时，可动用死库容应急供水。
- 有些水库会在死水位以下设**最低生态流量放水设施**。
```
┌─────────────────┐  ← 校核洪水位（极限）
│                 │
│   调洪库容       │  ← 防洪库容的一部分
│  （拦蓄洪水）    │
├─────────────────┤  ← 设计洪水位
│                 │
│   防洪库容       │  ← 专为防洪预留的空库容（汛期）
│  （部分重叠）    │
├─────────────────┤  ← 正常蓄水位
│                 │
│   兴利库容       │  ← 可以正常调节使用的水
│  （调节库容）    │
├─────────────────┤  ← 死水位
│                 │
│    死库容        │  ← 平时用不到，压箱底
│  （淤积+垫底）   │
└─────────────────┘  ← 库底（河床高程）
```


# 标尺高程对应流量关系
>当河流、水库或渠道中的水位（标尺读数）达到某个高度时，通过该断面的流量（立方米/秒）是多少。

| 术语           | 含义                   | 单位          | 备注                |
| ------------ | -------------------- | ----------- | ----------------- |
| **标尺高程（水位）** | 水面的海拔高度，或相对于某固定基面的高度 | 米（m）        | 如“黄海高程55.20米”     |
| **流量**       | 单位时间内通过断面的水体体积       | 立方米/秒（m³/s） | 1 m³/s = 1000 L/s |
| **水位-流量关系**  | 水位与流量之间的函数关系，通常是一条曲线 | -           | 一般水位越高，流量越大       |

# 水头
>**水头**是单位重量水体所具有的**机械能**，单位是**米（m）**。它反映了水从高处流向低处时的“推动力”，**上游水位与下游水位的高程差**

$$H=z+\frac{p}{\gamma}+\frac{v^2}{2g}
$$

| 项                  | 名称                                    | 含义                       | 工程意义          |
| ------------------ | ------------------------------------- | ------------------------ | ------------- |
| $z$                | **位置水头**                              | 水体相对于基准面的高度              | 水的“位能”，主要来源   |
| $\frac{p}{\gamma}$ | **压力水头**                              | 水体承受的压力（γγ为水的重度）         | 管道、承压含水层中有此贡献 |
| $\frac{v^2}{2g}$​  | **流速水头**                              | 水体流动的动能                  | 通常较小，占1%~5%   |
| 术语                 | 含义                                    | 备注                       |               |
| **总水头**            | $H=z+\frac{p}{\gamma}+\frac{v^2}{2g}$ | 水体的总能量                   |               |
| **位置水头**           | 海拔高度 $z$                              | 水库上游水位与下游水位的**高程差**是主要来源 |               |
| **压力水头**           | $p/γ$                                 | 有压管道、承压含水层中重要            |               |
| **流速水头**           | $v^2/(2g)$                            | 一般较小，但高速水流不可忽略           |               |
| **损失水头**           | $h_f​$                                | 沿程摩阻损失 + 局部损失（弯头、阀门等）    |               |
- **水头**：水的**总能量**（位置压能+动能+压力能）。
- **净水头**：**实际用于发电或驱动水轮机的有效水头**（总水头减去各项损失）。
- **水尾**：通常指**水轮机的尾水位**，即水流经水轮机后排出时的下游水位。

# 净水头
>**净水头**（Net Head）是指**实际作用在水轮机转轮上、用于做功的有效水头**。它是总水头减去各项水头损失后的剩余值。

$$H_净=H_毛−∑h_{损失}$$

| 损失类型       | 来源                    | 估算值（经验）                           |
| ---------- | --------------------- | --------------------------------- |
| **进水口损失**  | 水流从水库进入引水管道时的收缩、摩擦    | 0.1 ~ 0.5 m                       |
| **沿程摩阻损失** | 水流在引水管（隧洞、压力钢管）中与管壁摩擦 | $h_f=λ\frac{L}{D}\frac{v^2}{2g}$​ |
| **局部损失**   | 弯头、阀门、渐变段、分岔管等        | $h_j=ξ\frac{v^2}{2g}$             |
| **尾水管损失**  | 水流从转轮排出到尾水渠的动能损失      | 通常较小                              |

# 水电站的发电公式
$$
P=η⋅ρ⋅g⋅Q⋅H_净​
$$
其中 $P$ 是功率（W），$η$ 是效率，$Q$ 是流量（m³/s），$H_净$​ 是净水头（m）。


# 水尾
>**水尾**（Tailwater）通常指**水电站或水轮机下游的尾水位**，即水流经水轮机排出后，进入下游河道的水面高程。

| 术语      | 含义                | 用途          |
| ------- | ----------------- | ----------- |
| **尾水位** | 水轮机出口处的下游水位高程（m）  | 计算净水头（下游水位） |
| **尾水管** | 水轮机出口的扩散管，将水流引向下游 | 回收部分动能，提高效率 |
| **尾水渠** | 尾水管后的明渠，将水送回河道    | 电站尾水布置      |
