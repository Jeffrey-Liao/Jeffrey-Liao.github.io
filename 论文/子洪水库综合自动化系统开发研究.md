# 洪水预报的重要性
>根据河流**上游的来水或流域上发生的暴雨**，经过水情信息采集、传输、存储、处理和一系列的科学计算，最终**预估**出在流域 1：3 断面或河流下游水文站**即将发生的实际洪水过程**。

合理有效的洪水预报能够：
- 提前**预估**未来洪水
- 时判断**洪水的淹没范围**
- 防洪调度决策**提供技术支持**
- 为防灾减灾**赢得宝贵时间**

# 减灾措施
## 1. 分洪
>在河流险区上游**将超过河道安全泄量**的洪水**分流至邻近河流**、**湖泊**或[**蓄滞洪区**](#蓄滞洪区)的水利措施，旨在**削减洪峰**并**降低下游防洪压力**。其通过分洪闸、分洪道等设施控制流量，待**洪峰过后再将蓄滞洪水排回原河道或入海**。
## 2. 蓄洪
>蓄洪是我国防洪工程体系的核心组成部分，主要**通过水库、洼淀等设施在汛期临时贮存洪水**，实现**削减洪峰流量**、降低下游防洪压力的核心功能，是保障流域防洪安全、应对超标准洪水的关键“底牌”。

## 消减洪峰以及错峰
>是分洪和蓄洪的目的，**把洪水最高的“尖峰”部分给削掉、降低**或者**让两条以上河流的洪峰，在不同时间流到汇合点**。
### 核心调度
## 拦洪
>**用大坝、水库等把洪水直接拦在河道里，不让它往下游跑**
## 泄洪
>**当水库水位过高，逼近安全极限时，主动开闸把水放出去**

# 蓄滞洪区
>指**河堤外临时用来存水的低洼地区，包括行洪区、分洪区、蓄洪区和滞洪区等**。通常是正常的耕地或村庄。但当发生超大洪水，河道快扛不住时，就会**主动在这里开口或开闸**，把部分洪水暂时引进来，以牺牲局部利益来保护下游大城市、重要交通线等更核心的区域。

# 山西省水库现状
>山西省现有水库 **600**多座，其中**中小型水库占百分之九十以上**。

## 中小型水库的管理问题
- 由于受经济技术条件等各方面的限制，大部分建成以后**缺乏有效的管理**，经营手段落后。
- 一部分水库**无水情观测设施和通讯设备**
- 有部分的水库有通信设施也是**缺乏维护，大多陈旧落后，可靠性差**，当发生暴雨洪水灾害时，无法正常发挥作用
- **资料整编、洪水测报及洪水调度等均靠*人工处理***，效率低、人为误差大、准确性低。
- **洪水预报主要采用** [**降雨径流相关方法**](#降雨径流相关方法)，预报*精度低*，预报过程采用人工计算，费时费力，导致水库防洪调度困难

# 降雨径流相关方法
>把复杂的自然过程抽象成一个系统：**输入是降雨，输出是流域出口的洪水流量过程线**。核心就是要解决水量平衡和汇流时间这两个大问题。

## 1. 产流计算(计算净雨量)
>雨水落到地面，会经历植物截留、填洼、下渗、蒸发等损失，扣除损失后就是最后会形成洪水的水量
### 蓄满产流（湿润地区的典型模式）
>土壤像海绵一样，先吸水，吸饱了（田间持水量达到100%），之后降的雨就全部变成地表径流。
- **前期影响雨量**（雨前土壤有多湿），这直接决定后续降雨有多少会变成径流。
### 超渗产流（干旱/半干旱地区的典型模式）
>在植被差、土壤板结的干旱地区，如果暴雨来得特别猛，雨水来不及下渗，直接就流走了。
- **降雨强度**与**土壤下渗能力**的比较。下渗能力会随时间衰减，通常用“霍顿下渗曲线”来描述。雨强大于下渗率的差值部分，就是地面径流。


## 2. 汇流计算(计算洪水过程线)
>如何从山坡汇入小河，再汇入大河，形成出口处的洪水过程线
### 坡面汇流
**指净雨从山坡汇入河网的过程**。通常用**单位线法**来处理，最经典的是“时段单位线”：假设在一个特定流域，1毫米的均匀净雨在一个时段内降落，会形成一条固定的、形状像小山一样的出流过程线。因为假设系统是线性的，10毫米净雨形成的洪水，就是1毫米时的流量乘以10倍。
### 河网汇流
指洪水在河道里向下游“步进”的过程。此时洪水的形状会发生变化，特征被称为**坦化和推移**：
- **坦化**：洪峰变矮，历时变长。
- **推移**：洪峰到达的时间被推后。  
    常用的算法是**马斯京根法**，它通过一个参数，根据上游断面的流量过程，计算出下游断面流出的流量过程。

# 单位线
>一个特定流域，在特定时段内均匀降下1毫米的净雨，它会在流域出口形成一条什么样的出流过程线？

## 倍比性
>如果1毫米净雨形成的出流过程线是 `U(t)`，那么2毫米净雨形成的出流过程，在同一时刻的流量就是1毫米时的2倍，即 `2 × U(t)`。这是一种线性假设。

## 叠加性
>如果一场降雨分成了两个连续的时段，每个时段都产生净雨，那么**最终的总出流过程线，就是这两个时段各自净雨产生的出流过程线**，在时间上错开叠加的结果。

## 推求步骤
1. **选择雨洪资料**：选一场雨强均匀、时空分布好的单峰洪水。
2. **分割基流**：把河里的水分为“之前就在流的地下水”和“这次降雨产生的洪水”两部分，我们只关注后者。
3. **计算净雨**：用产流方法（如蓄满产流、初损后损法等）求出这次降雨过程中，有效净雨量及其时程分配。
4. **反推出流过程**：已知总出流过程和净雨过程，利用**最小二乘法**等数学工具，反解出那条符合倍比性和叠加性的“1毫米净雨”对应的标准出流过程，即**时段单位线**。

## 断面的指纹信息
- **洪峰**：代表调蓄能力。峰形尖瘦，说明流域调蓄能力弱，洪水来得快（如山区小流域）。
- **峰现时间**：指单位线从开始到洪峰出现的时间，反映了流域的汇流时间。
- **总历时**：指单位线从起涨到退水结束的时间，是流域对1毫米净雨记忆的总时长。

# 入渗方程
>计算**水渗入土壤的速度**的数学公式

## 霍顿方程
>土壤的入渗能力不是无限快的。降雨**开始**时，干燥**土壤吸水很快**，但**随着表土含水量增加**，入渗**速率**会从很高的“初始入渗率”**指数级地衰减**，最终趋近于一个稳定的“稳渗率”。
$$f(t)=f_c+(f_0-f_c)e^{-kt}$$
- $f(t)$：$t$ 时刻的**入渗率**。
- $f_0$：**初始**入渗率（降雨开始时土壤有多“渴”）。
- $f_c$​：**稳定**入渗率（土壤喝饱后能以多快速度往下传水）。
- $k$：**衰减常数**（决定了入渗率从快到慢的衰减速度）。

## 格林-安普特方程
>水在土壤中**下渗**，主要**受土壤基质吸力（土壤对水的吸附力）和重力共同驱动**
$$f(t)=K_s(1+\frac{\psi \Delta \theta}{F(t)})$$
- $f(t)$：入渗率。
- $Ks$​：土壤饱和**导水率**（水在饱和土壤中受重力能流多快）。
- $ψ$：湿润锋面的**基质吸力**（土壤能把水“吸”住的力量）。
- $Δθ$：土壤饱和含水率与初始含水率的差（土壤还能装多少水）。
- $F(t)$：累计入渗量。
