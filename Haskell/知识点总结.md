## 函数（重点）

---

### 1. map

- **作用：对列表中每个元素应用一个函数**
- 输入（input）：一个函数(a->b) + 一个列表 `[a]`
- 输出（output）：新列表 `[b]`

```haskell
map :: (a -> b) -> [a] -> [b]  
map (+1) [1,2,3]   -- [2,3,4]
```


---

### 2. filter

- **作用：筛选满足条件的元素**
- 输入：条件函数 + 列表 `[a]`
- 输出：过滤后的列表 `[a]`

filter :: (a -> Bool) -> [a] -> [a]  
filter even [1..10]   -- [2,4,6,8,10]

---

### 3. foldl

- **作用：从左到右累积计算**
- 输入：函数 `(a -> b -> a)` + 初始值 + 列表
- 输出：一个值

foldl :: (a -> b -> a) -> a -> [b] -> a  
foldl (+) 0 [1,2,3]   -- 6

---

### 4. foldr

- **作用：从右到左计算**
- 输入：函数 `(a -> b -> b)` + 初始值 + 列表
- 输出：一个值
```haskell
foldr :: (a -> b -> b) -> b -> [a] -> b  
foldr (+) 0 [1,2,3]   -- 6
```

---

### 5. head

- **作用：取列表第一个元素**
- 输入：非空列表 `[a]`
- 输出：元素 `a`

head :: [a] -> a  
head [1,2,3]   -- 1

---

### 6. tail

- **作用：去掉第一个元素**
- 输入：非空列表 `[a]`
- 输出：列表 `[a]`

tail :: [a] -> [a]  
tail [1,2,3]   -- [2,3]

---

### 7. take

- **作用：取前 n 个元素**
- 输入：Int + 列表 `[a]`
- 输出：列表 `[a]`

take :: Int -> [a] -> [a]  
take 2 [1,2,3]   -- [1,2]

---

### 8. drop

- **作用：丢弃前 n 个元素**
- 输入：Int + 列表 `[a]`
- 输出：列表 `[a]`

drop :: Int -> [a] -> [a]  
drop 2 [1,2,3]   -- [3]

---

### 9. length

- **作用：计算列表长度**
- 输入：列表 `[a]`
- 输出：Int

length :: [a] -> Int  
length [1,2,3]   -- 3

---

### 10. reverse

- **作用：反转列表**
- 输入：列表 `[a]`
- 输出：列表 `[a]`

reverse :: [a] -> [a]  
reverse [1,2,3]   -- [3,2,1]

---

### 11. elem

- **作用：判断元素是否在列表中**
- 输入：元素 `a` + 列表 `[a]`
- 输出：Bool

elem :: Eq a => a -> [a] -> Bool  
elem 3 [1,2,3]   -- True

---

### 12. concat

- **作用：把多个列表合并成一个**
- 输入：列表的列表 `[[a]]`
- 输出：列表 `[a]`

concat :: [[a]] -> [a]  
concat [[1,2],[3,4]]   -- [1,2,3,4]

---

### 13. replicate

- **作用：重复某个元素 n 次**
- 输入：Int + 元素 a
- 输出：列表 `[a]`

replicate :: Int -> a -> [a]  
replicate 3 5   -- [5,5,5]

---

### 14. zip

- **作用：把两个列表配对**
- 输入：两个列表 `[a]` `[b]`
- 输出：列表 `[(a,b)]`

zip :: [a] -> [b] -> [(a,b)]  
zip [1,2] ['a','b']   -- [(1,'a'),(2,'b')]

---

### 15. zipWith

- **作用：对两个列表对应位置进行运算**
- 输入：函数 + 两个列表
- 输出：列表

zipWith :: (a -> b -> c) -> [a] -> [b] -> [c]  
zipWith (+) [1,2] [3,4]   -- [4,6]

---

### 16. even

- **作用：判断是否是偶数**
- 输入：Int
- 输出：Bool

even :: Int -> Bool  
even 4   -- True

---

### 17. odd

- **作用：判断是否是奇数**
- 输入：Int
- 输出：Bool

odd :: Int -> Bool  
odd 3   -- True

---

### 18. sum

- **作用：求和**
- 输入：数值列表 `[a]`
- 输出：数值 `a`

sum :: Num a => [a] -> a  
sum [1,2,3]   -- 6

---

### 19. product

- **作用：求乘积**
- 输入：数值列表 `[a]`
- 输出：数值 `a`

product :: Num a => [a] -> a  
product [1,2,3]   -- 6

---

### 20. maximum / minimum

- **作用：最大值 / 最小值**
- 输入：列表 `[a]`
- 输出：元素 `a`

maximum :: Ord a => [a] -> a  
minimum :: Ord a => [a] -> a```
